# 产品概述 - Wugou CLI

## 产品目的
Wugou CLI 是对 Google Gemini CLI 的一个扩充实现，它在保留 Gemini CLI 核心能力的基础上，针对企业级使用场景进行了定制和扩展，解决了标准 Gemini CLI不支持OpenAI兼容API的问题在中文支持、本地化集成和特定工作流适配方面的局限性。

## 目标用户
**主要用户群体：**
- **企业开发团队**：需要本地化部署模型等使用自定义模型节点和定制化功能的技术团队

**用户需求和痛点：**
- 现有开源Coding Agent CLI工具对多模型支持非常弱
- 企业环境需要本地化的安全控制和合规性支持

## 关键功能

1. **企业级扩展**：
   - 增强的安全控制和审计功能
   - 支持企业内部的模型部署和调用
   - 提供管理控制台和用户权限管理

2. **开发者工具链增强**：
   - 针对中文技术栈的专门优化
   - 集成国内常用的开发工具和框架
   - 提供中文错误提示和解决方案建议

3. **社区和生态**：
   - 中文技术文档和教程体系
   - 活跃的中文用户社区支持
   - 定期的中文技术分享和培训活动

## 业务目标

- **中文开发者体验优化**：成为中文开发者首选的 AI 命令行工具，提升开发效率 40% 以上
- **企业市场渗透**：在 18 个月内获得 500+ 企业客户的采用和部署

1. **中文优先体验**：

2. **开放与兼容**：

   - 开源代码，接受社区监督和改进建议

3. **企业级可靠**：
   - 提供稳定可靠的企业级服务质量
   - 严格的数据安全和隐私保护措施
   - 完善的客户支持和技术服务体系

4. **社区驱动发展**：
   - 积极听取中文技术社区的反馈和建议
   - 鼓励社区贡献和生态共建
   - 定期举办技术活动，促进知识分享

5. **持续创新**：
   - 紧跟 AI 技术发展前沿，不断优化产品功能
   - 探索新的应用场景和用户需求
   - 推动中文 AI 开发工具的技术进步

## 监控与可见性

- **仪表板类型**：基于 Web 的实时监控仪表板，支持中英文双语界面 (http://localhost:49256)
- **实时更新**：WebSocket 连接提供实时状态和指标更新，支持中文指标展示
- **显示的关键指标**：
  - 当前活跃会话数和中文用户活动分析
  - API 使用率和响应时间统计（区分中英文查询）
  - 中文处理准确率和用户满意度评分
  - 系统资源使用情况和性能监控
  - 中文特定功能使用频率和用户行为分析

- **共享功能**：
  - 支持生成中文报告的只读分享链接
  - 提供符合国内企业格式要求的性能报告导出
  - 历史数据查询和趋势分析，支持中文可视化
